# JGA

Web-App für den Junggesellenabschied mit Bar Wheel und Task Wheel.

## Inhalt

- `bar_wheel/` – Interaktives Spinning Wheel zur Barauswahl
- `jga_tasks/` – Task Wheel mit Herausforderungen
- `shirts/` – Generierung der T-Shirt-Motive

## Nutzung

Einmal als GitHub-Pages-Seite hosten und dann über die Hauptseite navigieren.
